Help & User Guide

MICO360 GMap Scrapper

Getting started

  1. Double-click start.bat. The first run sets up a Python environment and downloads a browser engine (about 150 MB) — this takes a few minutes, once.
  2. Your browser opens automatically at http://127.0.0.1:8000. If it doesn’t, open that address manually.
  3. Leave the black command window open while you work — it’s the running server. Press Ctrl + C in it to stop.

Running a search

  1. Type a query such as dentists in Karachi or law firms in Dubai.
  2. Set Max results (how many listings to collect).
  3. Optionally tick Extract emails to visit each business website and harvest published email addresses. This is slower but adds contact emails.
  4. Click Start scraping. Progress and a live activity log appear as results stream in.
  5. Use Stop to end early; collected rows are kept.

Working with results

  • Filter — type in the search box to narrow rows by name, address, email, etc.
  • Columns ▾ — show or hide any of the 20 data fields.
  • The stat cards summarise how many listings have emails, phones, and websites.

Exporting

Click ↓ XLSX (Excel) or ↓ CSV to download the current results. Files are saved to your computer’s Downloads folder. Clear empties the table.

Settings & auto-update

The gear icon (⚙) opens Settings. Click Check for updates to see whether a newer version is available on GitHub, then Update now to download it. After updating, stop and re-run start.bat to load the new version. A backup of your current files is made automatically.

Troubleshooting

The page says “offline” / “Can’t reach the local server”

Make sure the start.bat command window is still running, and that you opened http://127.0.0.1:8000 (not the HTML file directly).

“Results feed not found — Google may be showing a CAPTCHA”

Google occasionally challenges automated traffic. Stop the server, set the environment variable HEADLESS=0, re-run start.bat, and solve the CAPTCHA in the browser window that appears. Slower, smaller batches also reduce challenges.

“Port 8000 in use” when starting

An old copy is still running. Close any previous scraper/command windows, or find and stop the process: netstat -ano | findstr :8000 then taskkill /PID <pid> /F.

The banner warns the browser engine failed to start

Stop start.bat and re-run it. If it persists, delete the .venv folder and run start.bat again to reinstall.

No emails were found for some businesses

Not every business publishes an email on its website, and some sites block automated access. Missing emails are normal.

Tip: email extraction visits each business’s homepage and contact pages, so runs with it enabled take noticeably longer. Turn it off for a quick listing-only pass.

FAQ

Is this affiliated with Google?

No. It is an independent tool and is not affiliated with or endorsed by Google. See the Terms & Conditions.

Is scraping Google Maps allowed?

Automated access may conflict with Google’s Terms of Service, and you are responsible for your own compliance. Please read the Terms & Conditions and Privacy Policy.

Where is my data stored?

Only on your computer — in the browser while running, and in the files you export. Nothing is sent to us.
